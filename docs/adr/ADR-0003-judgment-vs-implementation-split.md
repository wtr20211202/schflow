# ADR-0003：判断与实施分层（修码剥离）

- 状态：accepted（先行流水线决策 #3，2026-10-02）
- 落点：S/E（分工纪律 → schflow 的 judge 钩子 vs runner）
- 关联：design.md §3-D1/D3

## 背景

编排器最初亲自修回归/修平台差异——高判断模型做修码是全链最贵的组合。

## 决策

高判断模型只做诊断/分类/派发/合并判断，绝不亲自修码；修码统一派廉价执行模型。曾评估「编排整体换廉价模型」——否决：派发参数自检/破坏性命令纪律/rebase 冲突分类是低频高后果判断点，正是贵模型价值所在。

## schflow 映射

「判断贵/执行廉」从时间维细化到事件维：tick 零模型成本，六个判断钩子按需触发高价模型（design.md §3-D3）。
