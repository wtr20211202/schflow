# ADR-0009：常驻验证实例验证的是合并整体

- 状态：accepted（先行流水线决策 #9，2026-10-02）
- 落点：P（code kind 的 Profile 资产）

## 背景

批末全量回归跑在常驻验证实例上，曾混淆「它验证什么」。

## 决策

常驻验证实例 = 独立数据面的回归专用实例：批末用**合并后代码**整体重建——验证多支合并后的整体行为，非单提案；实例保持跑最新已提交代码，供人与其他会话随时查看。

## schflow 映射

实例管理属 code Profile（需要起实例的项目才配）；「保鲜」职责归 Profile 命令，不进引擎。**v1.0.10 回填**：本 ADR 的常驻验证实例已收敛为 §8 环境池的内置特例之一（envs.yaml 声明 + setup/teardown 钩子承载部署与保鲜）。
