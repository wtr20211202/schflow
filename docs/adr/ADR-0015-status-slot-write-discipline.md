# ADR-0015：状态槽位写纪律（最小插入）

- 状态：accepted（先行流水线决策 #15，2026-10-10）
- 落点：E（schflow 中被结构化存储彻底消解）
- 关联：0025、0026

## 背景

编排器重写台账头行注记时整行重生成，把一批 8 条的 [已批准] 状态槽整体剥掉——提案员对账连告警两轮；单文件台账不在版本控制，无法回放。

## 决策

头行注记只做**最小插入**；状态方括号必须保留或按流转刷新；写后自查状态槽仍在。

## schflow 映射

问题在 schflow 中结构性消失：任务卡是结构化文件、状态转移唯一出口 `store.Transition()`（自动落事件）——不存在「重写散文行」的写法。
