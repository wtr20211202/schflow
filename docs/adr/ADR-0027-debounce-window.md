# ADR-0027：攒批去抖窗

- 状态：superseded-by-0030（先行流水线决策 #27，2026-11-01）
- 落点：D
- 关联：0005、0030

## 背景与演化

提案低频期（单批 2~5 支），「自然停顿即跑全量」让单支合入也独占一轮长回归。改为：自然停顿触发前过 3 小时去抖窗（首支未背书合并起算），留窗收同伴；修复后重启回归豁免（红轮闭环要快）。性质：只在流水线整体空闲时才真等，代价上限=单支收口晚 ≤3h。

## 教训

自动触发语义随批次规模漂移（0005→0027→0030 三连改）证明：**低频期任何自动全量都是错配**——终局是按需制（0030）。

## schflow 映射

无对应机制（被 0030 取代）。
