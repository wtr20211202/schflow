# ADR-0018：门禁并发队列锁 + 重置前 WIP 保全

- 状态：accepted（先行流水线决策 #18，2026-10-18）
- 落点：P/E
- 关联：design.md §8、§17.4

## 背景

多槽并行同时跑重量级门禁（共享缓存的文件锁排队），旧策略 5×30s 重试不够排队时长，健康代码被判门禁红触发无谓修复回环；另一事故：槽位重置（回收冲突/配额墙任务）时把未提交的工作树改动直接清掉，丢工作。

## 决策

① 共享门禁资源用独立队列锁串行（等待上限 30 分钟，锁随进程退出释放无死锁）；② 槽位重置前强制 WIP 保全：树不干净 → 打快照提交到该任务分支并记哈希（树干净跳过）。

## schflow 映射

verify 命令链的资源互斥属 Profile（可声明共享锁）；WIP 保全是执行池回收的引擎硬步骤。
