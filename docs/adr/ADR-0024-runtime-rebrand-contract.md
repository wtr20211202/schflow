# ADR-0024：运行时标识变更的契约跟进

- 状态：accepted（先行流水线决策 #24，2026-10-25；泛化自一次产品更名事件）
- 落点：P

## 背景

目标产品整体更名（模块/数据目录/环境变量/部署标识层切换），流水线侧三处隐性断链：凭据链仍指向旧路径（静默失效，靠系统级兜底才没断推送）、刷新脚本数据目录、提示词自述——变更后推送实证才暴露。

## 决策

运行时标识（名称/路径/环境变量）变更时：①盘点全部引用面（凭据链/脚本默认值/提示词自述/文档口径）；②逐处跟进并实证（推送/刷新各跑一次）；③「有意不动的兼容面」显式立档（哪些旧名保留、为什么），防止后续会话误当残留去清理。

## schflow 映射

属仓库运维纪律（CONTRIBUTING/ADR 流程）；schflow 自身配置里的路径/名称集中在 schflow.yaml 与 hosts 包，变更走本 ADR 清单。
