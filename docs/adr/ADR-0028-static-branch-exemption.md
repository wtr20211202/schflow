# ADR-0028：静态支免全量

- 状态：absorbed-by-0030/kind（先行流水线决策 #28，2026-11-01）
- 落点：D
- 关联：0027、0030、design.md §6.3

## 背景与演化

纯文档/静态站/CI 改动的合并也独占一轮长回归——回归验证的是应用二进制，对此类合并信息量为零。改为机械判定：合并 diff 全部路径不匹配构建相关模式 → 免计免跑，合并时直接收口（从紧原则：混入任一构建相关文件即照常）；此类支验收=定向验证+评审，不含整合背书（逻辑必然而非选择）。

## schflow 映射

泛化为 kind 体系的一部分：非 git 轨道/轻量任务天然无全量概念；git 轨道内的「构建相关模式」判定作为 code Profile 的改动面谓词（when: go-changed 同族）。
