# ADR-0004：运行无时限，死运行只提示

- 状态：accepted（先行流水线决策 #4，2026-10-02）
- 落点：E
- 关联：0014、design.md §9 契约底线

## 背景

原设 2 小时自动超时，误伤合法长任务（大型提案实跑 3.5 小时+）。

## 决策

不设自动超时；疑似死运行（无进展且零消耗超阈值）只在台账记一行提示（同 runId 不重复），不自动终止；用户手动终止后走既有「中断折叠」路径（[受阻] + 槽位回收），重新批准即再入流水线。

## schflow 映射

执行池活性判据：以落盘面证据（runs/ 产物 mtime、转写增长）为准；引擎永不自动杀长任务。
