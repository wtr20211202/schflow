# ADR-0019：真实使用实例与外部数据面安全阀

- 状态：accepted（先行流水线决策 #19，2026-10-18）
- 落点：P

## 背景

用户长期自用的真实数据实例与回归测试实例并存：测试实例可随意重置播种，真实实例数据绝不可动；曾靠纪律约束，险些出事。

## 决策

① 真实实例用独立数据目录；刷新脚本入口强制「构建相关文件无未提交改动才启动」「优先复用同 HEAD 构建产物（避免重复构建）」；② 回归脚本对外部数据目录强制不重置不播种（双保险：路径判定=绝对路径且不在仓库内）——**安全阀在脚本层，不靠会话自觉**；③ 会话纪律：绝不手工清空/移动/播种真实数据目录。

## schflow 映射

多实例/数据面策略属 code Profile；「外部数据目录安全阀」模式适用于一切带真实数据的 Profile 命令。**v1.0.10 回填**：真实使用实例在 §8 环境池中标记 `protected: true` 永不入池——本 ADR 的安全阀经验由租约机制与该标记共同承载。
