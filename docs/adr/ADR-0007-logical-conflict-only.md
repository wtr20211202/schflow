# ADR-0007：只治逻辑冲突，文件重叠交串行合并

- 状态：accepted（先行流水线决策 #7，2026-10-04）
- 落点：D（判断钩子①策略）
- 关联：0020、design.md §8

## 背景

冲突治理三代演化：文件级保守归组串行 → 模块亲和性同组 → 定案。文件重叠串行化严重伤害并行度。

## 决策

派发前逐对只判**逻辑冲突**（同目标异方案/行为互斥）：能判优→择优执行另一条暂缓、优者落地后暂缓方标 [已过时]；不能判优→双暂缓提请用户裁决。文件/组件/键重叠**不串行**——合并期严格串行 rebase 兜底（机械冲突当场解、语义冲突 [受阻] 注明、合并后复验）。「依赖: P-xxx」声明且目标未终结→暂缓派发（不占位，向下取合格候选）。
