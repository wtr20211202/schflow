# ADR-0026：状态判定层（机读唯一来源）

- 状态：accepted（先行流水线决策 #26，2026-10-26）
- 落点：E
- 关联：0025、0015、design.md §2/§6

## 背景

LLM 对台账散文阅读三致事故（0025 为第三起）后立：根治 = 换判定介质。

## 决策

脚本按「标题后首个状态方括号」口径提取全量状态/优先级/依赖/标题，生成机读 JSON；编排与提案员**一切状态判定只读 JSON**；生成失败 fail-closed（跳过状态相关动作——宁停线不退回散文阅读）。首跑即揪出两条「叙事收口但状态槽未翻」的漂移实锤。附带格式门禁：状态词后紧跟标题（拦标题内嵌劫位）。

## schflow 映射

更进一步：任务卡原生结构化（task.yaml），散文层只作人读视图——判定层与事实源合一，漂移面归零。
