# ADR-0031：折叠时效/补位硬约束 + 门禁链减负 + 心跳（合集）

- 状态：accepted（先行流水线决策 #31，2026-11-10/11-15，多次增补）
- 落点：E/D
- 关联：0001、0017、design.md §8/§17

## 背景

一条大型拆解任务实跑 14 小时，其中约 7.4 小时为非工作死区：配额墙后 8 个 tick 未折叠未补位（2.6h 空转）、无依赖子步骤拖 4.5h 才补位；另有多起「工具视图陈旧误判挂死」（实为在跑）、跨拓扑脚本无参误跑全量 8 小时、定时任务 68 分钟派发空窗无法归因。

## 决策（子项）

a) **折叠时效硬约束**：在途任务每 tick 实查状态（禁凭记忆默认在跑）、非运行态当 tick 处置、跨 ≥2 tick 未处置=违规；活性存疑以落盘面证据（产物/转写 mtime）为准——工具进程视图可能陈旧（多起撤回教训）；b) **已解锁子步骤补位硬约束**：依赖步已合或无依赖 + 空槽 ⇒ 当 tick 补位，禁「留待后续顺手」；c) 跨拓扑/全量类脚本 **fail-closed**：无显式参数/清单拒绝执行（两次 8h/53min 白跑实案）+ 可达性预检；d) 执行器禁手动重跑全量门禁——并发自验限单包秒级，排队/超时走「待补后置」通道；e) 门禁链减负：①各段计时输出（后因运行时可重放约束退役为纯标签）；②无验证需求的步骤跳过构建起实例段；③前端单测按改动面收窄（共享层改动才全量）；④合并闸零交集跳过（主线增量与本支改动文件集无交集 ⇒ 仅静态复核即合——两个各自验证过的树的无交集并集）；⑤race 档按包收窄；⑥Linux 门禁改动面自动跳过（无 Go 侧改动且无删除 ⇒ 整段跳过）；f) **tick 心跳**：无条件落盘心跳时间戳，间隔超阈值台账留痕——宿主离线与调度违规事后可判定；g) 运行体禁取时间戳/随机数等非确定源（可重放性约束——需计时放命令内部）。
