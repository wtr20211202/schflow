# ADR-0014：全量红与流水线解耦 + 环境方差治理

- 状态：accepted（先行流水线决策 #14，2026-10-07）
- 落点：D（回归治理子系统）
- 关联：0030、design.md §8

## 背景

曾因「全量连红 → 编排器自作主张挂起待合至全量绿」整夜零推进（全部槽位被待合支占死）。

## 决策

① 待合即合适用于一切非运行窗口，全量失败**不冻结合并**，禁止「挂起至全量绿」；② 失败先对账已知基线册：全在册=基线红照常放行；③ 册外失败先单实例串行复跑一次（替代整轮重跑，40min→15min），自愈即放行；④ 两轮复现才升级修复——逐轮落盘失败集比对，单轮抖动归环境方差（并行负载下追单轮方差是死循环根源）。

## schflow 映射

「回归治理」子系统：基线白名单（附归因）、串行复跑、两轮复现升级、修复器有界轮次——code kind 的 Profile 可选项。
