# ADR-0017：燃料链——任意模型 + 可用性顺延 + 自动切换

- 状态：accepted（先行流水线决策 #17，2026-10-11/10-18/10-25 多轮修订）
- 落点：P（模型池）
- 关联：0016、design.md §9 模型池

## 背景

多模型配额墙频发（周配额、冷启动、中途断供）；曾据进度指标误判「挂死」实为长命令/限流自适应扇出（多个实案）。

## 决策

- 选模：链序 × 在列 × 非冷静期 × 在途<上限，全挡取冷静期最先到期者；
- **断供判定三条件缺一不可**：①运行时自报异常持续 >10min；②该运行真实活动枯竭（落盘产物 mtime >25min 无更新）；③同模型其他运行同样满足①②（或不存在）——**禁止单看进度/消耗指标判死**（两者是步骤级/结算级口径，长步骤期间天然陈旧）；
- 配额墙带重置时刻必须记绝对解冻时间（不能 30 分钟冷静期空撞硬墙）；墙内低频探针自动感知充值/重置（近墙不探、单发不探）；
- 切换=原任务书全量重派（续跑类 API 不携带任务参数的教训——禁止只换模型不换任务书的调用形态）；冷启动饿死与中途断供两形态同治，先做相关性核对再判计划级断供。

## schflow 映射

模型池（链/上限/冷静期/探针）为 Profile 配置；活性判据以 runs/ 落盘面证据为准。
