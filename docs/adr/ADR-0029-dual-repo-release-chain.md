# ADR-0029：双仓发布链适配定案

- 状态：accepted（先行流水线决策 #29，2026-11-07）
- 落点：P

## 背景

私有开发仓 + 对外发布仓双仓结构：发布链（导出白名单→扫描闸→发布叙事门禁+人工外推）已自闭环，评估流水线主干是否需要适配。

## 决策

① 版本叙事（CHANGELOG 类）**不接管**——发版时的叙事提交是锚点驱动的整体重写，单支提案自动追加只能产碎片；② **公开导出影响声明是提案义务**：新增对外可见文件族的提案必须声明并在拆解中含导出清单同步步骤（白名单制下新增文件默认不导出且无报错=静默漏发布）；执行侧自查：任务书遗漏而实际新增 → 顺手补清单并注明；③ 公开发布前的写作纪律（旧名残留/断链清扫）列入提案来源视角之一。

## schflow 映射

对外发布类仓库的 Profile/方向配置示例：导出清单同步作为 verify 前的阶段模板项；「版本叙事不接管」= 交付物契约不含 CHANGELOG 重写。
