# ADR-0025：领取判定硬化（只认状态槽）

- 状态：accepted（先行流水线决策 #25，2026-10-26）
- 落点：E
- 关联：0026

## 背景

一条最高优先级提案批准后约 50 个 tick、18 小时零领取零台账。两个误读源：注记里的历史词「保持待决策」被当状态（无视 [已批准] 槽）；「依赖: P-x」按声明原文暂缓——目标当日早已收口，依赖已解除。连同此前两起同类事故，共性 = **对台账头行做子串式散文阅读而非槽位判定**。

## 决策

① 状态判定只认标题后的状态槽，注记旧词不算；② 依赖标记必须核对目标**当前**状态，已终结即解除照常领取；③ 队列报告义务升格为一切阶段：存在已批准未派发必须报告并说明暂缓原因，禁止静默结束。

## schflow 映射

在 schflow 中结构性消解：判定只读任务卡结构化字段（0026）；「报告义务」固化为 tick 事件输出（board/log 可查）。
