# ADR-0012：待合即合（四守卫）

- 状态：accepted（先行流水线决策 #12，2026-10-06）
- 落点：E
- 关联：0002、0011

## 背景

「全部终结才开合」在滚动批次下造成队头阻塞：2 个慢任务（3.5 小时级）堵 6 支待合、堵全部槽位、堵百余条已批准队列，利用率 2/8。

## 决策

执行完成的分支即刻进入合并（滚动），四守卫不变：全量回归未在跑 / 修复器不在途 / 合并锁空闲 / 主树干净。每合一支立即释放槽位接补位——慢任务只占自己的槽。

## schflow 映射

合并队列常态化（merging 阶段降级为兜底）；守卫集硬编码（design.md §8）。
