# ADR-0006：提案时效性三岔 + 已过时终态

- 状态：accepted（先行流水线决策 #6，2026-10-02）
- 落点：D
- 关联：design.md §4.3、§9 契约底线

## 背景

提案是产生时点的快照；代码演进后提案前提可能已不成立，照做即浪费一轮执行。

## 决策

三层防线：①提案员每轮顺带为受影响提案追加修正注记（最便宜）；②执行器动手前必做时效校验三岔——成立→实施 / 锚点漂移→按意图适配并注明 / 前提不成立→返回 stale；③编排器把 stale 折叠为 [已过时] 终态（零改动收官，不重试）。

## schflow 映射

三岔是 executor 阶段模板默认开（result 结构化字段 stale）；[已过时] 终态入状态机。
