# ADR-0010：推送主体唯一（快进-only）

- 状态：accepted（先行流水线决策 #10，2026-10-02）
- 落点：E
- 关联：0023、design.md §8

## 背景

全链提交曾只落本地盘——误 reset/仓库损坏即丢全部实跑成果。

## 决策

执行器/修复器**只 commit 不 push**；推送统一由编排器承担（两处推送点：每合一支即推 + tick 级兜底，覆盖修复器直提交与重试）；一律快进-only 绝不 force；失败只记不阻塞（降级为延迟保护而非停摆）。曾评估「执行器自推分支」——否决：合并前 rebase 重写历史必然非快进，需引入 force 例外与远端清理，复杂度不值。

## schflow 映射

只有合并队列推（design.md §8「推送主体唯一」）；引擎零凭据，鉴权下放 git credential。
