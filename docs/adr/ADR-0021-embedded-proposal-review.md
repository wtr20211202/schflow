# ADR-0021：提案产出内嵌冷眼评审

- 状态：accepted（先行流水线决策 #21，2026-10-24）
- 落点：S（proposer skill 内嵌，不开独立角色）
- 关联：design.md §4.2

## 背景

提案常被直接批准进入自动循环——单遍产出与人工批阅之间没有质量闸。

## 决策

提案员每轮草稿定稿后、入台账前，必经一个**冷眼子代理**七维评审（必要性/合理性/可用性/便捷性/安全性/可靠性/扩展性；安全性按**部署环境基线**校准——只拦真实暴露面〔公网入口/凭据明文/注入/提权/数据出域〕，禁止理论性加固否决小改进）。处置：否决不入账（记因，清空则继续找候选防空手）；修改即修订；通过附评审行入账。评审同轮完成（子代理失败重试一次后降级为「入账+标注未评审」，不阻塞产出）。子代理可读仓库代码核验「已存在能力」断言——对单遍误判的第二道防线。

## schflow 映射

proposer skill 的内嵌阶段（design.md §3 极简定案：评审同轮完成，不独立成 skill）。
