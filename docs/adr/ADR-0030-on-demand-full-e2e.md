# ADR-0030：全量回归按需制

- 状态：accepted（先行流水线决策 #30，2026-11-07）
- 落点：D（code kind Profile）
- 关联：0005、0013、0027、0028

## 背景

提案低频期全量边际收益较大批次时代掉一个量级（近两周真实捕获 1~2 例/轮 vs 历史 5~8 例/轮，均为跨域相互作用类），而成本不变（约 1.2h 运行 + 分诊 + 修复期间合并暂停 2~4h）。

## 决策

① 触发=显式请求标记（删标记即取消），守卫=无在跑/无修复在途/主树干净；启动后周期内全自动闭环（分片并行/基线对账/册外串行复跑/修复有界轮次/修复后重启）——裁决链保留伺候手动轮；② 收口语义简化：合并闸（定向复验 + 调用点补测）过 → 即标 [已做]；自动攒批/去抖/静态免计等记账全部退役；③ 存量「待全量」形态批量迁移收口。用户知悉并接受的代价：跨轮用例债静默积累至手动轮一次性归因；tip 局部回归由真实使用承担首发发现。

## schflow 映射

回归治理默认关闭、标记触发；「合并闸即收口」对齐「验收=定向验证+评审」的交付语义。
